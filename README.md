# 命運之手：台灣（Fate of Formosa）

作者：gudubi（gudubi@gudubi.com）・官方網站：[gudubi.com](https://gudubi.com)・原始碼：[github.com/gudubi/fate-of-formosa](https://github.com/gudubi/fate-of-formosa)

以 Three.js 製作的網頁模擬遊戲。從**此刻的真實時間**開始，玩家以「命運之手」介入事件，陪台灣走過 30 年。

## 執行

```bash
npm install
npm run dev        # 開發伺服器（--host，同網段的手機與平板可直接連線測試）
npm run build      # 輸出至 dist/，可部署到任何靜態網站主機
npm run simulate   # 無畫面批次模擬 300 局，檢查平衡
npm run check-history  # 檢查「歷史上的今天」資料格式與日期涵蓋
npm run publish:site -- <資料夾>  # 建置並放進網站資料夾（相對路徑，可放在任何子目錄）
```

## 時間設計

| 項目 | 數值 |
|---|---|
| 一局長度 | 30 年（約 10,958 天） |
| 標準速度 | 4 天／秒，純時間約 45.7 分鐘，加上決策時間約 1 小時 |
| 2× 速度 | 8 天／秒 |
| 4× 速度 | 16 天／秒 |
| 開場 | 以真實時間流動 2.5 秒，再於 10 秒內加速到標準速度（×1 → ×345,600） |

### 每日事件機率

| 層級 | 每年平均 | 說明 |
|---|---|---|
| 快訊 | 26 次 | 只顯示在跑馬燈，小幅影響數值 |
| 一般事件 | 15 次 | 地圖冒出泡泡，30 天內可干預，逾期交給天意 |
| 重大事件 | 2.4 次 | 時間暫停，必須決定；同一局不重複 |
| 固定排程 | — | 總統大選（每四年 1 月）、九合一（每四年 11 月） |

## 主要機制

- **事件不倒數**：一般事件可以慢慢想；同時待決超過 5 件時，最舊的一件交給天意。
- **選項預覽**：▲▼ 表示影響方向與幅度，虛線框為長期政策（移動數值的平衡點）。
- **天候**：全球景氣、對岸態度、世代認同、社會氛圍、經濟依賴等背景因子。
- **中立性**：兩岸緊張度與經濟依賴度互為鏡像，偏向獨立或偏向統一各有代價。`npm run simulate` 以「固定偏統／固定偏獨」機器人比較分數，差距超過 2 分即警告。
- **五年回顧、里程碑、成果指數**，以及結局時的「若不出手」對照（同一種子碼、同樣的事件與運氣，全程不干預重跑一次）。
- **結局畫面**：分十年回顧、關鍵抉擇與精簡數據，版面以手機一次截圖為目標；完整數值與走勢圖收在下方。
  每局結局都會存在本機，標題畫面的「過往結局」可以重看（最多 20 筆）。
- **種子碼**：標題畫面自動產生 6 碼種子碼，可按「重新生成」更換，或按「複製連結」取得 `?seed=XXXXXX` 形式的分享連結；
  從帶有 `seed` 參數的網址進入時會自動填入，標題畫面的網址也會同步種子碼。同一天用相同種子碼開始的玩家，會從同一個世界出發。
  引擎分成兩條亂數：「世界」決定事件何時發生與背景因子（每天固定消耗，不受玩家選擇影響），「天意」決定順其自然的結果與事件鏈。
  事件地點與新聞寫法由「種子碼＋日期＋事件」雜湊決定。因此即使各自做出不同選擇，事件節奏與背景因子仍保持一致。
- **彩蛋**：30 個稀有事件（外星訊號、恐龍化石、《待曉詩篇》熱潮、海峽上空的另一座島……），每局平均約 1.3 個、最多 3 個，
  不和一般事件搶抽籤池；各有專屬地圖特效與音效。標題畫面的「彩蛋圖鑑」記錄跨局看過的彩蛋與結局；彩蛋不影響統獨與經濟依賴。
- **本機紀錄**：保留前 10 名，點選紀錄可帶入該局種子碼再挑戰一次。
- **離線**：正式版註冊 Service Worker，可安裝到手機桌面。

## 專案結構

```
src/
  sim/        純邏輯模擬（不依賴畫面，可在 Node 執行）
    engine.ts       數值連動、事件抽選、選舉、結局
    systemEvents.ts 選舉、海峽危機、宣告統一／獨立
    types.ts        事件資料格式（新增事件請看這裡）
  data/events/  事件資料 JSON（台灣情境 229 個、全球與社會重大事件 30 個、彩蛋 34 個）
  data/history/ 歷史上的今天（01–12.json，約 1,280 則，依月份延遲載入）
  map/          投影（1 單位 = 1 公里）、縣市柵格、地形
  render/       Three.js 場景
  ui/ audio/    介面設定、合成音效
tools/
  prepare-map.ts  重新產生地圖資料（npx tsx tools/prepare-map.ts）：geo.json、
                  縣市柵格 public/map/ids.png 與地形 public/map/height.png（建置時算好，啟動不必計算）
  simulate.ts     平衡模擬
docs/ASSET_PROMPTS.md  圖片素材提示詞
```

## 新增或調整事件

在 `src/data/events/*.json` 加入符合 `src/sim/types.ts` 中 `EventDef` 的物件即可。完成後執行 `npm run simulate`，它會先檢查資料格式，再回報：

- 結局分布
- 各數值走向
- 從未發生的事件

## 資料來源

| 圖層 | 來源 | 授權 |
|---|---|---|
| 縣市界線 | 內政部國土測繪中心「直轄市、縣市界線（TWD97 經緯度）」，經 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas) 簡化 | 政府資料開放授權條款；taiwan-atlas 為 MIT |
| 周邊國家 | Natural Earth，經 [world-atlas](https://github.com/topojson/world-atlas) 整理 | 公眾領域 |

「歷史上的今天」整理自維基百科日期與年份條目、政府網站及新聞資料，日期經交叉查核；無法確認日期的條目已排除。

地形是依主要山脈稜線（中央、雪山、玉山、阿里山、海岸山脈等）近似建模，並非真實 DEM。
